PRIMESIGHT

A dispatch goes in, and the crew's phone gets a one-screen briefing on the building: who is inside (CoStar), what the floor looks like (Matterport 3D scan read by SAM 3), and what is outside (Vexcel aerials and hydrants). Pick any building, floor and emergency; nothing is hardcoded.

1 · Send a dispatch (pick one)

Judge modeThree columns: building, floor stack, emergency. "Surprise me" picks a random combination. Texts land on the phone. CAD consoleA dispatcher's form: address search, floor, incident type, people, caller, notes, time of call. Free textType it like radio traffic. Addresses and incident types autocomplete; the live parse shows what Primesight reads. MapEvery preprocessed building on a map of Houston and LA. Green dots: SAM 3 has scanned the floor.

2 · Watch the agent (put one on the projector)

TimelineEach step as it happens, helpers indented, then the briefing with each line tagged by data source. Agent graphThe deepagents layout: main agent, three subagents, tools and the file system. Nodes light up as they are used. Data layersFour columns, one per data source, filling in as the agent pulls them. Shows how many layers one text draws on. Building stackThe building floor by floor with people counts, the marked floor plan, and the crew's phone beside it. Ops boardTime to text, steps, helpers, grader verdict, cost, texts queued for building staff and tenant flags.
Projectors follow the newest run from any console. Add ?speed=3 to play a recorded run faster.

3 · The crew's phone

Phone (judge line)What Engine 1 sees. Judge mode texts here. Reply to ask follow-ups, or text NOTE ... to leave a note for the next crew. Phone (your own line)Open on any phone on the same Wi-Fi. Text an address and an emergency, just like a dispatch.

Running the demo

  1. Open a projector on the big screen and judge mode on a laptop.
  2. Have a judge pick a building, floor and emergency, then press Text it to the crew.
  3. The projector shows the agent working (30-60 s live, instant with recorded runs); the briefing lands on the phone.
  4. Reply from the phone ("which elevator fits a stretcher?") to show the agent remembers the call.
